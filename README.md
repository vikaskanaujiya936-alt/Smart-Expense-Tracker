# 💰 Smart Expense Tracker

A desktop-based expense management application built using **Python and Tkinter**.

## 📌 Project Overview

Smart Expense Tracker helps users record, manage, search and analyze their daily expenses through a simple graphical interface.

## ✨ Features

- ➕ Add and manage expenses
- 🔍 Search expenses
- 📊 Category-wise expense chart
- 📅 Monthly expense summary
- 💰 Total expense calculation
- 📝 Track total entries
- 📆 Today's expense tracking
- 🎯 Set monthly budget
- ⚠️ Check budget status
- 📤 Export expenses to CSV
- 👀 View all expenses

## 🛠️ Technologies Used

- Python
- Tkinter
- CSV File Handling
- File Handling
